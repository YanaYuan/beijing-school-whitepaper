# 北京小学与初中择校白皮书

面向京籍家庭的公开研究协作项目。政策基准为 **2026 年**，首轮核验日期为 **2026-10-25**。候选学校不是官方排名，历史招生名额不代表未来录取保证。

- **在线阅读：** https://yanayuan.github.io/beijing-school-whitepaper/
- **正文：** [index.html](./index.html)
- **讨论与补充证据：** [创建 Issue](https://github.com/YanaYuan/beijing-school-whitepaper/issues/new/choose)
- **修改正文：** [在 GitHub 编辑](https://github.com/YanaYuan/beijing-school-whitepaper/edit/main/index.html)
- **待审核修改：** [Pull Requests](https://github.com/YanaYuan/beijing-school-whitepaper/pulls)

## 内容

1. 研究范围和证据分级。
2. 海淀、西城、东城、朝阳的初中候选及已核实招生计划。
3. 学籍、户籍、房产、实际居住与回区资格。
4. 从初中倒推小学的直升、定向名额和派位路径。
5. 志愿录取顺序、校额到校及跨区风险。
6. 家庭行动路线、空白决策模板、13 项官方或权威来源。

## 如何参与

**不熟悉 HTML：** 创建 Issue，指出具体章节、问题、适用年份和公开来源。维护者可以据此整理修订。

**希望直接修改：**

1. 登录 GitHub，打开 `index.html`，点击编辑按钮。
2. 没有写权限时，按提示 Fork 仓库，在自己的分支修改。
3. 提交 Pull Request，说明改动与证据。
4. 维护者审核并合并至 `main` 后，GitHub Pages 部署更新。

公开仓库不代表任何人能直接覆盖主稿；普通参与者可以通过 Issue 和 Pull Request 协作，不需要提前授予写权限。长期维护者由仓库所有者单独邀请。这里是异步版本协作，**不是实时富文本共同编辑器**。

## 内容与隐私规则

- 政策结论应优先链接教委、考试中心等原文，注明行政区、学段、年份、具体学校或校区。
- 家长亲历、媒体报道、分析意见与官方事实分别标注。
- 不用高中成绩代替初中培养质量，不把不同校区数据混用。
- 不转述未经核实的“保进”“付费名额”或精确中签率。
- 不发布学生姓名、证件、家庭住址、手机号、个人预算或可关联具体孩子的学籍信息。
- 正文中的家庭表格是空白模板。真实家庭信息只在私人副本中填写，不能提交到公开仓库。
- Git 提交、Issue 和评论会公开，并可能保留历史；删除当前页面中的隐私信息不等于清除了历史。
- 用自己的文字总结来源，不整篇复制第三方文章或未经授权的图片。

## 阅读、打印与下载

本项目没有外部脚本、字体、分析统计或第三方运行依赖。

- 直接用浏览器打开 `index.html`。
- 顶部“打印 / 保存 PDF”使用打印专用布局。
- 顶部“下载 HTML”保存独立文件，离线可读。
- 小屏幕上的宽表格可在表格区域横向滚动。

## 发布方式

GitHub Pages 从 `main` 分支的仓库根目录发布。`.nojekyll` 标记本项目为无需 Jekyll 处理的静态站点。部署状态可在仓库的 Actions / Pages 设置中查看。

修改后应检查目录锚点、来源链接、移动端表格和打印效果。更新政策时同时修改适用年份与版本记录，不将旧年度名额直接外推。

## 责任边界

文档由 AI 辅助整理公开资料，供研究与讨论使用，不构成官方入学承诺、学校质量认证或购房建议。涉及迁户、买房、转学、回区等不可逆决定，请以目标年度的正式政策和主管部门审核为准。
